Open problems

  • Rotation. The effective-theory construction is under control for the non-rotating case. A Kerr analog, with a well-posed surface, frame dragging, and a discrete spectrum, is what can actually be compared with LVK data.
  • Formation. Collapse with a nucleating de Sitter core is no longer an empty subject. There is, for example, a 2026 Phys. Rev. D letter on forming a gravastar from dust. How generic that is, and what happens when the progenitor is spinning, is still open.
  • Echo templates. Searches need waveforms: discrete surface modes, a time delay that depends on compactness, and a template that disappears into detector noise the way a real echo would.
  • Electromagnetic tests. EHT polarimetry, photon-ring substructure, and possible light echoes. The exterior is Schwarzschild or Kerr at first look. The question is which of the next decimals is not.

Existing constraints

Echo claims in the early LIGO data sat at about 1.5σ. The collaboration treated them as noise. Searches in O3, and later model-agnostic work on loud events including GW150914, found no significant post-merger echoes and set amplitude limits. Those papers should be cited. A model that predicts a loud echo in the existing data is already in conflict with them.

The 2023 Universe review says the ringdown is not yet precise enough to test the discrete spectrum. That gap is the one worth writing into.
